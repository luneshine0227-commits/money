使用說明

第一次使用建議從頭看一次，之後隨時可以回來查看

🚀 快速上手（建議依序做）

  1. 商品設定：先把你賣的商品建起來（例如生髮膠囊、果乾水…），之後新增訂單才能直接選，不用手打
  2. 支出項設定：建立贈品、運費等成本項目（會自動算出單位成本），再設定「滿額禮門檻」（例如滿1000送A）
  3. 商品設定 → 買就送規則（選填）：如果有「買A送B」這種跟金額無關、只跟商品有關的贈品，在這裡設定
  4. 進貨紀錄：記錄每次進貨，之後訂單會自動用平均進貨單價算出成本；代理補貨改在「新增訂單」裡直接填
  5. 新增訂單：選商品、填數量與各通路金額，系統會自動判定滿額禮／買就送、算出成本與利潤

⚠️ 資料保存最重要的 3 件事

  • 所有資料都只存在這個瀏覽器、這台裝置，不會自動上傳、也不會跟其他裝置或瀏覽器同步
  • 換裝置、換瀏覽器、清除瀏覽器資料／快取，資料都會不見，養成習慣三不五時到「💾 備份」頁面匯出備份檔，存一份在雲端硬碟
  • 瀏覽器儲存空間有上限（約 5MB，可記錄數千筆訂單），「備份」頁面可以看到目前用了多少，快滿了系統會提醒你

📱 手機使用小提醒

  • 打開後建議用瀏覽器的分享／選單功能「加入主畫面」，之後桌面會有一個像 App 的圖示，點一下就能開
  • 務必都用同一個瀏覽器 App 開啟（例如都用 Safari，或都用 Chrome），資料才會一直存在同一個地方

匯出備份

將目前所有訂單、支出項設定資料匯出成一個 JSON 檔案，可保存在雲端硬碟或傳到其他裝置。

選擇先前匯出的 JSON 備份檔還原資料。匯入將會覆蓋目前瀏覽器中的所有資料，請先確認。

清空所有資料

刪除這台裝置上儲存的所有訂單、進貨/代理補貨紀錄、商品與支出項設定，此動作無法復原。

👋 開始使用前，先看這裡

這個工具的所有資料都只存在「這個瀏覽器」裡，不會自動上傳、也不會跟其他裝置同步。

請務必養成習慣：三不五時到「💾 備份」頁面按「匯出備份檔」，存一份在雲端硬碟，避免換裝置、清瀏覽器資料時整份記錄不見。

手機的話，建議加入主畫面或釘選書籤，之後開啟才會一直抓到同一份資料。
